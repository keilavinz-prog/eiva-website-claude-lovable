# EIVA website CLAUDE/LOVABLE

Crea una plantilla web básica en blanco, en español, de una sola página. Solo estructura con textos de relleno, sin imágenes, sin animaciones, sin backend ni funcionalidades extra. Secciones: cabecera con "Tu logo" y menú (Inicio, Sección 1, Sección 2, Contacto), sección de inicio con "Título principal", un párrafo de relleno y un botón, "Sección 1" y "Sección 2" con título, párrafo y un recuadro vacío con borde discontinuo, "Contacto" con título y recuadro vacío, y pie de página con "© 2026 — Nombre de la empresa". Estilo neutro y limpio, responsive. Nada más.
